# 工程脚本

日常编译和检查从仓库根目录运行 `build.ps1`、`test.ps1`。脚本内部使用自身位置解析仓库根目录，不要求先切到脚本目录。

| 目录 | 用途 | 执行边界 |
| --- | --- | --- |
| `common` | SDK 选择、仅当前进程生效的环境设置与恢复 | 不修改系统环境 |
| `build` | 发布、依赖许可与校验、安装器 | 正式发布检查已提交源码；安装器工具下载保留签名核验 |
| `assets` | 生成图标 | 输出到指定目录或源码 Assets |
| `test/ui` | 操作隔离 QA 实例并检查实际界面 | 提供应用路径及新的结果路径；不替代真实系统重启验收 |
| `test/sandbox` | 沙盒启动器与来宾测试 | `*Guest.ps1` 不能在宿主运行；保留沙盒账户/文件边界检查 |
| `test/local` | 宿主安装器检查 | 检测到已有正式安装即拒绝覆盖；优先使用 Sandbox |

功能测试工程和模拟客户端已移到 `tests`，不再放在 `tools/fixtures`。脚本调用方法见 [开发说明](../docs/DEVELOPMENT.md)。
