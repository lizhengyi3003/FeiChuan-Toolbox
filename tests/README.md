# 测试与隔离夹具

`TunHotspot.Tests` 是现有控制台功能检查，使用独立临时目录和专用注册表测试键，不要求 NuGet 测试框架。运行 `../test.ps1 -Offline` 可先检查工程引用和脚本，再运行全部功能检查。它不通过 `dotnet test` 自动发现用例。

`Fixtures/Kumiryo.Client` 是带原生消息循环的模拟客户端，`Fixtures/Kumiryo.Integration` 是配置迁移集成驱动。二者只用于隔离验证，不会通过产品构建或发布入口加入安装包。夹具有自己的模拟客户端版本，不能作为正式产品版本更新。

界面脚本在 `tools/test/ui`；需要创建服务、重开模拟客户端或测试权限边界的来宾脚本在 `tools/test/sandbox`。来宾脚本的宿主拒绝条件必须保留，不能为了方便调试而删除。各脚本需要独立的输出目录，避免把旧结果误认作本轮通过。
