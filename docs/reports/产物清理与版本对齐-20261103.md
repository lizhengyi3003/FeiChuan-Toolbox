# 产物清理与版本对齐 · 2026-11-03

当前产品维护版本统一为 1.5.3。源码结构整理后的产物也纳入本轮清理：不再保留顶层几十个旧发布目录和多套模拟客户端运行库。

## 去向与删除范围

- 历史交付包按真实版本移到 artifacts/archive/releases，保留原包、旁校验和原发布元数据。
- 旧展开构建完整压缩到 archive/builds，逐文件核验 ZIP、数量、长度和 SHA-256 后才删除原展开目录；每份归档有文件清单与包 SHA-256。
- 数据库/设置恢复原件、源码备份放 backups；诊断、测试、截图和迁移回执放 reports；不把私有资料放入 current。
- 删除过期模拟客户端/驱动的自包含发布副本、bin/obj 及上轮验证构建；测试源码、原始源码 ZIP、测试结论和截图保留。
- 旧 Android 与 SDK 下载资料移入 archive/development-tools，.tools 仅保留当前构建缓存。

迁移前源码原件：artifacts/backups/source-before-cleanup-20261103.zip。全量操作和旧新路径映射：artifacts/reports/cleanup-20261103/migration.json；逐步记录 operations.jsonl。历史报告中的归档内路径使用 ZIP!内部路径表示。

## 工程约束

Directory.Build.props 是产品版本入口；程序集、当前手册、README、更新记录与生成分发的版本一致。协议、数据库、第三方依赖、Kumiryo 和模拟客户端版本保持各自含义。历史记录保留真实版本及结论。

完整发布先在 temp 构建 app/安装包/便携包，全部校验成功才更新 current；现有 current 不在构建过程中混入新文件。默认拒绝脏源码正式发布，本地验证显式指定 -WorkingTree 并记录 sourceDirty=true。

严格分发检查实际发现旧 SHA-256 输出使用 ASCII 导致中文包名被替换为问号；当前输出改用 UTF-8，校验值、中文文件名、ZIP 内每个文件均一致才允许切换 current。首次失败回执保留。删除这份失败临时构建被自动审批返回 blocked by policy，未给出更具体原因；改为保守搬迁到 archive/failed-builds 并明确标记，不混入当前分发。

本轮构建、功能、界面、分发校验和最终节省空间以本机 completion.json 为准。没有因清理而重置运行数据、改代理/热点或停远控；系统安装版不在清理范围内。

## 最终结果

- 旧布局迁移 117 个动作：71 项分类移动、21 份完整旧构建归档、25 项可再生成输出删除。
- 删除旧生成内容约 2.68 GiB；旧构建压缩另减少约 3.70 GiB。此为清理阶段回收量，新 1.5.3 产物、重新编译缓存及失败留档另计。
- artifacts 顶层只保留 current、archive、reports、backups、temp、README.md 和 index.json。源码及依赖缓存各有独立用途。
- 六个工程构建、128 项功能检查、31 个脚本语法和 69 个引用检查通过；完整运行目录和便携 ZIP 逐文件校验通过，安装器文件版本一致。
- 三组界面自动化通过，其中日志用三个独立 QA 实例验证，避免固定 30 秒窗口在后续用例前关闭；保持真实筛选断言。设置截图有效，托盘桌面截图判为不采信并保留，未把它当成外观验证。
- 系统安装版仍为 1.5.2，当前项目及新生成分发为 1.5.3。要运行新版本，先退出托盘旧实例，再使用 current 中的安装包或完整运行目录。
