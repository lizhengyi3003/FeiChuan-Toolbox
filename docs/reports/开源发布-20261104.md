## 发布后的实际验收发现

1.5.6 的构建/证明/发布 job 成功，但下载端回读发现 GitHub 将中文附件名剥除，原清单中的下载 URL 因此失效。该版保留为不可变历史并在 Release 说明中注明问题；修复使用 1.5.7，不覆盖既有附件或强制移动标签。

1.5.7 在 Directory.Build.props 集中定义 ASCII DistributionPrefix，由安装器、便携包和自动更新清单共同使用。发布前检查本地资产名，再在草稿上传后核对平台实际名称、数量、内容摘要和 URL，发生归一化就停止公开。最终还须下载公开包校验，不能仅凭工作流绿色认定所有分发链路正常。

1.5.7 的新守卫停在草稿阶段：按标签读取正式发布的接口返回 404，且草稿实际使用临时 untagged URL。已按 Release ID 读回真实草稿，确认 9 个 ASCII 附件。1.5.8 分离草稿身份/摘要校验和公开后的正式 URL 校验，公共验证器供工作流和测试共用；6 项阶段/重命名/摘要/URL 回归通过。1.5.7 草稿不作为已公开交付。
