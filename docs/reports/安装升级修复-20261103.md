# 安装升级与恢复 · 1.5.4

本次针对 1.5.3 升级时后台 MCP 锁住 Engine DLL、权限不足、默认回退不完整的问题。历史复现见 [故障仿真](安装升级故障仿真-20261103.md)。

## 实际流程

1. 选择目录后检查本程序身份、实际路径、重解析点和写入权限。普通权限不足时交由 Windows UAC 提升安装器；提升后仍须是同一账户。静默模式权限不足直接失败。
2. 在准备页说明退出和恢复范围。按规范化目标目录取得并发锁，核对进程路径、账户、创建时间和持有句柄。只处理该目录的工具箱主界面、`Engine --mcp` 和热点工作进程，先发协作退出通知；旧版超时才结束已核实的该进程。拒绝按进程名批量结束或终止服务。
3. 不认识的 Engine 模式、其他账户的进程、反复拉起的旧进程、外部 DLL 占用或文件权限不足会停止更新。机器采集组件位于受保护的独立版本目录，不在退出范围。UU 远程、Kumiryo 与 Process Lasso 也不在退出范围。
4. 将将要覆盖的程序文件、旧卸载器和本应用安装登记保存在安装目录外，校验备份哈希。写入更新标记；新版本主界面和 Engine 检测到标记时停止启动，防止更新期间再次锁住 DLL。旧版本反复重启时停止，而不持续争抢。
5. Inno Setup 完成替换后，逐一回读安装清单的 SHA-256，成功后提交并移除标记。失败时在 Inno 自身回退之后恢复原件和安装登记，再回读校验。中断遗留的标记会在下次安装中识别；恢复失败则保留原件、标记和诊断，不伪报完成。

## 记录与恢复

每次安装生成独立 GUID 操作目录，包括 `state.json`、`steps.jsonl`、`files/`、`Recover.ps1` 和 `Restore.cmd`。具体路径写入安装日志。普通权限使用 `%USERPROFILE%\.FeiChuanToolbox\installer\operations`；提升权限使用 `%ProgramData%\TunHotspot\Installer\<当前 SID>\operations`，仅管理员与 SYSTEM 可写。备份不随安装包分发，不自动清理。

恢复须在原机器、原账户和相同权限下运行；提升操作的 Restore.cmd 须以管理员身份运行。恢复前检查原件哈希，安装已完成后还检查当前程序与本次安装一致，拒绝覆盖后续修改。恢复会退出本程序，并恢复本次触及的程序文件及安装登记；不回滚用户数据库，不重置网络或系统配置。原来已经混版时，恢复到安装前也仍是混版，应使用完整新包重新安装。

静默安装需要显式 `/CLOSEOWNAPPS=1` 才允许退出本程序；缺少此参数且程序运行时，会在替换前失败。故障注入参数仅在受控 WDAG 沙盒存在项目哨兵时接受，不能在正常机器注入校验失败。

## 边界

备份恢复涵盖程序内容与本应用卸载登记，不承诺还原文件安全描述符、快捷方式所有元数据或断电瞬间的全系统状态。新文件引入的空目录可能保留。不会绕过 Windows 保护或强行结束外部锁定者；拒绝原因和恢复路径应保留。当前未签名，管理员重启后不将主程序直接以管理员身份打开，可由开始菜单正常启动。

本轮协调流程用于安装和升级。卸载仍需先从托盘退出并断开工具箱 MCP，独立机器组件沿用卸载前的授权检查。

验证证据与当前通过情况见 [当前验收](../VALIDATION.md)。本轮仿真不等同于已升级宿主机安装版。
