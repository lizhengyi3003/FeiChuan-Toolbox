# 当前验收

当前产品版本：**1.5.5** · 2026-11-04。当前产物以 `artifacts/current/release.json` 为准。

本轮修复安装前申请 UAC 未弹出的交互缺陷；证据在 `artifacts/reports/installer-uac-20261104`，最终结果以 completion.json 为准。

- 已在宿主 Windows 11 26300 使用实际 1.5.5 安装包，从普通权限目录页触发原生 UAC。旧窗口退出，新进程为管理员令牌；账户 SID、原目标目录和 HKCU 安装语义均保留，协调器身份核对通过。见 host-uac-proof.json、host-parent-155.log、host-elevated-155.log。代理未点击安装按钮，验证停在替换文件前。
- 完整 Release 构建和 133 项功能检查通过；当前运行目录 731 文件、便携 ZIP 732 文件逐一核验；版本与 SHA-256 检查通过。
- 当前 1.5.5 安装包在隔离 Windows 11 26100 沙盒重跑的 12 项升级/恢复场景全部通过：静默授权边界、旧 MCP 与旧界面退出、新版协作退出、外部锁保留、权限拒绝、替换后回滚、更新中断恢复、关键控制进程保留和手动恢复冲突保护。故意校验失败返回 9，安装前所有文件及版本登记恢复一致。最终状态见 sandbox/output/installer-recovery.json。

旧入口的最小复现返回 False/错误码 5。早期只读检查包装程序因跳过目录页，出现零文件安装完成记录；未执行 Native 调用，作废为 UAC 证明。最终 UAC 结论取自实际 1.5.5 安装包的普通父进程与管理员子进程，不能以安装完成字样替代令牌核对。

后续发现遗留检查窗口的 `{app}` 过早读取报错，所属为 UacHandoffProbe，非正式安装器。已核对路径与父子进程后关闭测试进程，保留正式管理员安装窗口；测试入口改为显示目录页、仅在目录页读取安装路径、捕获错误后退出，并由 PrepareToInstall 硬性阻止实际安装。修正后编译通过。隐藏窗口自动化未找到按钮，不作为交互成功证明；其 finally 清理已执行，无检查进程遗留。该修改仅涉及测试工具，不变更已验证的 1.5.5 安装包。

历史 1.5.4 的 133 项功能检查和 12 个沙盒安装回归见 [历史验收](安装回归验收-1.5.4.md)。该轮没有交互式 UAC 实测，不能作为本轮提权链路的证明。修复原因和范围见 [UAC 修复说明](安装提权修复-20261104.md)。
