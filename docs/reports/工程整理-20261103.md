本文记录首轮基于 1.5.2 的源码拆分；当时保留产物原位的安排已由后续 [1.5.3 产物整理](产物清理与版本对齐-20261103.md) 取代。

## 改动

- 三个产品工程保持在 `src`，功能检查和两个 Kumiryo 隔离夹具移到 `tests`；解决方案分别组织产品、测试和文档。
- Core 按启动管理、存储、设置、诊断、安全、热点、网络和 Kumiryo 配置划分目录；原 Models 拆为契约、扫描、监测、分析、设置和数据路径文件。
- WindowsScanner 按登录入口、打包应用、服务、任务、间接入口、扩展、WMI、进程和元数据整理；统一阶段/取消/覆盖编排不变。
- WinUI 主窗口拆成导航、生命周期、页面、控制、分析、监测、外观、托盘与 QA 文件；热点和配置的 XAML 页面成对归位。资源路径改为包内绝对 URI。
- Engine 分为安装、监测、控制、审计、MCP 和受保护的沙盒测试入口。
- 构建、图标、界面测试、宿主安装测试和沙盒脚本分目录，修正仓库根目录解析与跨脚本引用。
- 增加中央 NuGet 版本文件、共享临时 SDK 环境、统一 test.ps1 和工程引用检查；文档区分使用手册、当前设计与有日期报告。

本次没有升级依赖或产品版本，没有改变已有服务/应用/程序集标识、JSON 协议或数据库版本。已有安装版、后台服务、远控/代理状态及用户数据没有因目录整理而移动或重置。
