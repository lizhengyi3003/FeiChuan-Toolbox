# Kumiryo 配置与恢复

先安装并登录兼容的 Kumiryo 0.2.4。工具箱预检九个设置模块，保留目标电脑的账号、订阅和当前订阅选择。查看差异，确认退出兜底选项后执行。

初始备份与写入恢复备份分开显示。仅在备份、保存稳定性和进程身份均通过且本次明确授权时，可以结束客户端界面；不结束内核、服务或进程树。完成后以普通权限重开，逐项显示文件与运行检查。

失败时查看操作历史和恢复记录；字段后续被修改时停止覆盖。文件一致不代表全部内核设置已生效。不要导出或分享原始 DPAPI 文件、账号或订阅。

详见 [配置指南](https://github.com/lizhengyi3003/FeiChuan-Toolbox/blob/main/docs/guides/Kumiryo一键配置.md)。
