# 安装与验证

从 [官方 Releases](https://github.com/lizhengyi3003/FeiChuan-Toolbox/releases/latest) 获取 x64 安装器或完整便携 ZIP；运行用户不需要开发 SDK。当前未进行 Authenticode 签名，请核对 SHA256SUMS 和 GitHub 构建证明。

升级先退出本安装目录中的程序，再备份、替换和逐文件校验；失败保留恢复入口。数据独立存放于当前用户目录，不随程序卸载或便携 ZIP 自动迁移。DPAPI 备份通常需要原用户及原电脑。

参阅 [完整使用说明](https://github.com/lizhengyi3003/FeiChuan-Toolbox/blob/main/docs/guides/使用说明.txt) 与 [发布验证](https://github.com/lizhengyi3003/FeiChuan-Toolbox/blob/main/docs/RELEASING.md)。
