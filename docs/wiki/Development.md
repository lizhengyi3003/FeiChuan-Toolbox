# 开发与发布

安装 global.json 指定的 .NET SDK、PowerShell 7、Windows SDK 和 WinUI/C++ 构建工具。从 build.ps1、test.ps1 及 tools/security 的共享入口检查；本地数据与生成物不提交。

遵守 [贡献规范](https://github.com/lizhengyi3003/FeiChuan-Toolbox/blob/main/CONTRIBUTING.md)、[架构](https://github.com/lizhengyi3003/FeiChuan-Toolbox/blob/main/docs/ARCHITECTURE.md) 和 [发布流程](https://github.com/lizhengyi3003/FeiChuan-Toolbox/blob/main/docs/RELEASING.md)。主分支通过 PR 与 CI 维护，正式包只由与源码版本一致的 vX.Y.Z 标签生成。第三方通知和 GPL 源码随对应版本提供。
