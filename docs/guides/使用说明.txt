飞船的小工具箱 1.5.9 · Windows 11 x64

【运行与分享】
解压整个便携包，运行 TunHotspot.exe。不能只发送一个 exe。
也可发送 FeiChuan-Toolbox-1.5.9-Setup-x64.exe 安装包。
包含 .NET、WinUI、VC++ 运行文件，不需要开发环境、Codex 或 API 密钥。
当前未做代码签名，随包提供 SHA-256。

【Kumiryo 一键配置】
顶部第三个工作区，可迁移九个模块和 95 条自定义规则。
账号、登录凭据、订阅和当前订阅选择保留各电脑自身内容。
先查看差异并确认，再由独立工作进程备份、退出、原子写入、重新打开及核验。
支持普通执行、管理员核验及 UAC 执行；提权必须为同一 Windows 账户。
管理员模式限定当前账户标准配置目录；重开的客户端保持普通权限。
不强制停止 Kumiryo 服务、内核或远控服务。
备份用当前用户 Windows DPAPI 加密；日志不含配置原文、账号或订阅。
工作进程中断可由观察进程恢复；系统重启后可从页面处理未完成记录。
恢复拒绝覆盖之后发生的相关设置变化，失败时保留备份和日志。
配置文件完整不等于全部内核运行设置已生效；界面分别显示通过和待核对项。
本机资料在 %USERPROFILE%\.FeiChuanToolbox\KumiryoConfiguration。
未安装或尚未登录 Kumiryo 时先初始化客户端。直接验证版本为 0.2.4。
跨电脑可携带无凭据设置模板，不能将原始加密备份当作通用迁移包。

【扫描】
首次打开自动建立普通权限基线。顶部全局扫描按钮申请 UAC，或使用已安装的
机器组件，并显示阶段进度。取消授权后保留普通权限结果。
入口数量不代表开机常驻数量；手动、触发、禁用及实际运行分别核对。
存在访问限制、解析失败或其他缺口时会明确显示，不能保证发现一切私有机制。

【单项控制与恢复】
选中普通 Run/启动文件夹或第三方任务，可启用/禁用。
普通服务另有启动/停止及自动、延迟自动、手动、禁用启动类型。
先查看预览，再确认 UAC；执行前核对配置并备份，执行后读取系统实际结果。
改变启动类型不会自动启停；禁用入口也不会连带结束已运行的进程。
驱动、用户服务模板/实例、关键服务、Windows 系统任务、打包应用及间接入口
暂不直接修改，按钮旁会说明限制，可打开系统配置。保护远控和代理恢复通道。
“操作与恢复”可查看结果、同步管理员备份、恢复所选记录。
恢复前重新授权核对，拒绝覆盖后续变化；未核实的中断记录需先人工核对。
受控备份在本机 %ProgramData%\TunHotspot\Actions，按账户分开，不随便携包迁移。
本地历史副本不能替代管理员受控备份。没有批量停用或删除功能。

【持续监测和覆盖提醒】
在其他软件中设好状态后重新扫描，选中项目并点击“监视当前状态”。
发现偏离会先留档，再按设置发送 Windows 通知。通知被划掉后仍可在
“通知与关注”中搜索、查看证据、标记已读和重发。恢复后结案，再次偏离
形成新事件。软件不自动反复写回，也不推定一定是某个管家修改。
任务管理器和设置的开关可能操作同一配置，不是不同权限等级。
普通模式在 UI/托盘运行时监测可用范围；开机和完整进程事件需要机器组件。
设置中的“安装/更新开机采集组件”需要 UAC，只增加本软件的机器服务和
当前用户登录托盘入口。程序位于受控 Program Files，机器日志在 ProgramData。
退出托盘后机器服务仍可采集，通知由登录托盘进程发送。暂停与卸载不同。

【创建来源】
“Codex 创建”“DSH 创建”分别显示已确认记录与待核实的名称、路径关联。
软件本身的启动项不代表 AI 创建；没有证据时不猜测来源，也不会新建启动项。
在“全部启动入口”中选中任意项，可“标记创建来源”，填写确认或排除依据。
来源标记不会改 Windows；目标命令变化后要求复核。

【管理员两轮复核】
可运行 Engine\TunHotspot.Engine.exe --audit-scan，一次 UAC 完成两轮只读扫描。
结果保存在用户数据 audits 目录，总览可显示最近复核的时间、变化与覆盖缺口。
取消授权不算成功；两轮稳定只代表该次观测时段。

【分类和分析】
分类为建议保留、按需保留、可考虑取消、需修复、待分析；不是自动执行结论。
未知入口及已有未分析结果自动加入待分析区；可暂缓，配置变化后重新入列。
“分类浏览”支持类别、应用、建议、启用状态、实际运行、账户及创建来源。
“全部启动入口”和“待分析”筛选独立，支持显示数量和一键重置。
在待分析页面点击“连接本机 Codex”，按客户端提示刷新连接，再在对话中说：
“读取 TunHotspot 待分析区，分析必要性并把建议返回软件”。
软件不会自行启动模型推理或读取聊天数据库、登录凭据。
没有 Codex 时可导出脱敏分析 JSON，并导入对应批次的建议 JSON。
每批最多 100 项，优先未审核的当前项目。历史保留项须先重新扫描；
已有分析但证据不足的项会保留说明。只接受本机、当前指纹和合法字段；
不执行返回的命令。
脱敏不保证移除所有私人内容，导出预览后仍需人工核对。

【外观和托盘】
支持 Acrylic、Mica、MicaAlt、None、主题、DirectWrite 字体枚举和字号。
Mica 不直接透视其他窗口；系统高对比度和透明策略优先。不实现 Aero。
安装新字体后可以刷新列表。关闭窗口默认收起到托盘，真正退出请用托盘菜单。
托盘右键菜单也由 WinUI 3 绘制，跟随主题、字体和材质，支持 Esc、上下键和失焦关闭。
UI 请以普通权限运行；管理员采集由独立组件完成，提升权限的 UI 无法正常通知。

【原有热点】
先在 Kumiryo 中手动开启 TUN，然后进入兼容热点页点击“开启兼容热点”。
不用时点“关闭热点”，关闭 TUN 前先关闭热点。
启动、扫描和退出不会自动开关热点，也不改代理、DNS、防火墙或分流。
其他电脑需要核对网卡与 TUN 兼容性。

【迁移、更新与卸载】
复制到另一台电脑后建立该机的新数据，不携带原机数据库。
移动已安装机器组件的便携目录后，请在新位置安装/更新组件，以刷新托盘
启动路径；Codex 连接也需要重新注册。服务的受控程序路径不依赖便携目录。
更新和卸载前请从托盘退出。安装器不会终止其他软件。
卸载机器组件需要 UAC，会移除自身服务和登录入口，保留历史及受控版本。
安装版卸载时若机器组件仍存在，会先请求授权移除；静默卸载则要求先移除组件。
所有系统修改均须由你选择、预览并授权；模型返回的建议不会自动执行。
本版不保证权限高于所有管家、驱动或系统防护。

【数据】
用户数据：%USERPROFILE%\.FeiChuanToolbox
操作日志：%LOCALAPPDATA%\TunHotspot.WinUI
机器数据：%ProgramData%\TunHotspot\Monitor（管理员控制）
运行事件默认 7 天，配置快照 30 天。告警与建议历史独立保留，不随普通日志清空。
通知提交给系统不表示已经查看；磁盘写满时也不能保证持久保存。
完整重启轨迹、通知点击唤回和原生材质视觉效果还需在实际环境验收。

【全局设置和报错兜底】
顶部“设置”在所有工作区可见，外观、托盘与通知独立保存在 preferences.json，启动数据库损坏也能打开。错误提示包含编号、时间、错误码和日志位置；设置页可查看最近诊断。页面重试只重新读取，不自动重复启停、注入或恢复。日志目录失败时尝试备用目录，均失败会提示复制详情。

【安装升级与恢复】
安装器会检查目录权限，必要时请求当前账户管理员授权，并退出本目录的工具箱界面、热点工作进程和 MCP。先校验备份，写入后逐文件核验；失败恢复并保留操作日志和 Restore.cmd。用户数据与独立机器组件保留。静默升级需显式 /CLOSEOWNAPPS=1，权限不足或其他进程占用时停止。恢复路径见安装日志；提升备份的 Restore.cmd 需要以管理员身份运行。备份后程序发生变化会拒绝覆盖。
